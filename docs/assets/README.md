# 문서 이미지와 도식 관리

README와 사용자 안내에 넣는 이미지의 원본을 이 폴더에서 관리합니다. 파일 경로는 용도에 맞게 유지하고, 화면을 갱신할 때 같은 경로의 이미지를 교체합니다. 날짜나 버전 번호를 파일 이름에 붙여 사본을 계속 쌓지 않습니다.

```text
docs/assets/
├── README.md
├── screenshots/
│   └── web/
│       ├── new-conversion.png
│       └── help.png
└── diagrams/
    └── browser-processing.svg
```

| 폴더 | 용도 | 갱신 기준 |
| --- | --- | --- |
| `screenshots/web/` | 실제 웹 앱의 사용자 안내용 화면 | 주요 메뉴·문구·조작 방식이 바뀔 때 다시 촬영 |
| `diagrams/` | 처리 구조·저장 위치를 설명하는 편집 가능한 SVG | 실행 위치·모델 저장소·통신·이어하기 방식이 바뀔 때 원본 수정 |

다른 종류의 화면이 필요하면 `screenshots/<제품 또는 화면 종류>/`를 추가합니다. 문서 이미지와 무관한 실제 문서·모델·변환 결과는 넣지 않습니다.

## 현재 자산

| 파일 | 출처·내용 | 갱신일 |
| --- | --- | --- |
| `screenshots/web/new-conversion.png` | 로컬에서 실행한 실제 doc2audio 웹 앱의 새 음성 만들기 화면. 안내용 합성 예시만 사용 | 2026-09-13 |
| `screenshots/web/help.png` | 같은 실제 앱의 도움말 화면 | 2026-09-13 |
| `diagrams/browser-processing.svg` | 프로젝트 구현을 바탕으로 직접 작성한 벡터 도식. 웹 파일·모델 다운로드와 내 PC 내부 처리 경계를 표시 | 2026-09-13 |

스크린샷은 디자인 시안이나 AI 생성 이미지가 아닙니다. 예시 글은 설명용으로 작성한 합성 문장이고, 실제 사용자의 문서·이름·파일 경로·작업 기록을 사용하지 않습니다.

현재 PNG는 프로덕션 빌드의 기본 브라우저 모드를 Ego에서 촬영했습니다. 뷰포트는 1440×1100이며 페이지 전체를 저장해 새 음성 만들기는 1440×1490, 도움말은 1440×1503입니다. `samples/korean.txt`를 선택한 예시이며, 아직 모델을 받지 않은 첫 사용 상태를 그대로 보여 줍니다.

## 화면 갱신 방법

1. 변경된 코드로 웹 앱을 실행하거나 빌드합니다. 일반 이용자에게 보이는 브라우저 모드를 사용합니다.
2. 문서 이미지 전용 브라우저 프로필이나 격리된 저장소에서 실행합니다. 테스트용 합성 예시만 넣고 실제 사용자의 작업 기록이 노출되지 않게 합니다.
3. 새 음성 만들기와 도움말을 실제 브라우저에서 열고 화면을 촬영합니다. 개인정보·개발 도구·오류·잘린 문구가 없는지 확인합니다.
4. 위의 안정된 파일 경로로 교체하고 표의 갱신일을 수정합니다. 앱 변경으로 단계가 달라졌다면 README·웹 사용 안내·SVG 도식도 함께 수정합니다.
5. README에서 상대 경로 이미지가 열리는지, 화면의 글자가 읽히는지, SVG에 설명과 화살표가 겹치지 않는지 확인합니다.

SVG는 텍스트 편집기로 수정할 수 있는 원본입니다. 색이나 그림만으로 뜻을 전달하지 말고 단계·실행 위치·저장 위치를 텍스트로 표시하며, `title`과 `desc`를 유지합니다. Markdown에서는 각 이미지에 설명하는 대체 텍스트를 작성합니다.

## 제품 자산과의 구분

- `docs/assets/`: README와 안내 문서를 위한 이미지. 제품 동작에 필요하지 않으며 정적 웹 빌드에 자동 포함하지 않습니다.
- `apps/web/public/`: 웹 앱이 실제로 제공하는 파일. 예를 들어 `voice-samples/`는 **샘플 듣기**에 쓰는 공개 합성 음성입니다. 문서용 스크린샷을 이곳에 복제하지 않습니다.
- `output/`: 검증 로그·임시 스크린샷·개인 변환 결과. 사용자 문서 이미지로 채택한 공개 가능한 파일만 `docs/assets/`에 복사합니다.

사용자 개인 문서, 모델 가중치, 계정 정보, 실제 로컬 사용자 이름이 들어간 경로는 이 폴더나 README에 기록하지 않습니다.
