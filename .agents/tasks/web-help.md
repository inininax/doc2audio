# 배포 웹의 로컬 처리 도움말과 문서 자산

- 목표와 완료 조건: 일반 웹 사용자의 지정 폴더 모델 저장 가능성을 공식 자료로 조사하고, 실제 사이트 도움말과 README 스크린샷·처리 과정 자산을 추가하며 기존 로컬 실행 경로를 안내한다.
- 담당 도구·세션: root 통합·Ego QA·실제 로컬 실행 확인, storage_research 공식 API 조사, help_ui 화면·회귀 검사, help_docs 사용 문서·편집 가능한 도식.
- 상태: 완료
- 담당 파일·디렉터리: apps/web/src 도움말·입력 화면, README.md, docs 사용 안내·assets, 이 기록과 .agents/PROJECT.md.
- 브랜치·기준 커밋: main / 2311a7c. 시작 시 목소리 샘플 작업의 미커밋 변경 존재, 보존한다.

## 결정 사항

- 지정 폴더 저장 요청은 가능성 조사 범위다. IndexedDB 저장 구현을 바꾸거나 미구현 기능을 화면에서 사용 가능하다고 안내하지 않는다.
- 도움말은 배포된 정적 웹 사용자 기준이며, 기본 브라우저 실행과 선택적 로컬 Python 서버 실행을 명확히 구분한다.
- 실제 화면 스크린샷은 docs/assets/screenshots/web/, 편집 가능한 처리 도식은 docs/assets/diagrams/에 둔다. 개인정보와 환경별 절대 경로를 제품 설명·문서 자산에 넣지 않는다.
- 이번 요청에는 커밋·푸시·배포를 포함하지 않는다.

## 변경한 내용

- 주 메뉴의 도움말과 `#help` 직접 접속을 추가했다. 문서 입력의 ‘업로드’를 ‘파일 선택’으로 바꾸고, 현재 모드의 처리 위치와 도움말 링크를 표시한다.
- 브라우저와 로컬 서버의 7단계 처리·저장 위치, 오프라인·삭제·이어하기 FAQ를 각각 제공한다. 등록 전 초안과 등록 완료한 작업의 저장 차이를 설명한다.
- README를 일반 웹 이용자와 개발·배포자 안내로 나누고 실제 화면 PNG 두 장과 편집 가능한 SVG를 연결했다. `docs/assets/README.md`에 용도별 경로·갱신 기준·캡처 조건을 기록했다.
- `docs/model-storage.md`에 실제 폴더 저장 API와 권한·브라우저 지원·사이트 데이터 삭제의 영향을 조사했다. `docs/local-usage.md`에 기존 CLI·로컬 웹과 모델 폴더 지정 방법을 정리했다.

## 검증

- 실제 설치 환경에서 기본 Qwen 모델 파일, Python, ffmpeg, Metal GPU를 doctor로 확인했다. CLI로 합성 예시 43자를 Qwen3 1.7B/Sohee로 변환해 6.72초 MP3 생성·전체 ffmpeg 디코딩에 성공했다. 완료 구간 재사용은 0이었다.
- 웹 114개 + 서비스 워커 6개 테스트, 타입 검사·Prettier·빌드 통과. 빌드 캐시는 269개 파일, revision `89ef4780e0ebc6a1`이다. 작성자 외 검토자가 관련 테스트 23개와 타입 검사를 별도 재실행했다.
- Ego 프로덕션 화면에서 #help 직접 진입, 모델 미설치 상태 도움말, 도움말 왕복 후 선택한 파일·작업 이름 보존을 확인했다.
- 390px에서 가로 넘침이 없고 네 메뉴가 177×48px의 2×2 배치인 것을 확인했다. 실제 데스크톱·모바일과 SVG 렌더를 시각 검토했다.
- 페이지 네트워크 요청을 차단한 상태에서 도움말 새로고침·FAQ 펼치기·IndexedDB 설명 표시를 확인했고 비캐시 probe는 Failed to fetch였다. 이 검사에서 navigator.onLine은 true로 남아 OS 전체 오프라인 실험과 구분한다. 페이지 네트워크 설정은 복구했다.
- 8010 로컬 서버의 도움말도 실제로 확인했다. 최신 빌드 확인 때 해당 QA 탭에만 서비스 워커 우회를 적용하고 복구했다. 사용자 기존 탭·캐시는 삭제하지 않았다.
- 문서 상대 경로·PNG 형식/크기·SVG XML·AI 환경 연결·git diff --check 통과. UI, 사용자 문서·이미지, 폴더 저장 조사에 대한 작성자 외 독립 검토 완료. 발견한 아이콘 이름·로컬 재개 문구·조사 문서의 로컬 안내 링크는 수정했다.
- 증거는 Git에서 제외한 `output/web-help/`에 보관한다. 지정 폴더 모델 저장 API는 조사만 했으며 구현·브라우저별 실기기 검증은 하지 않았다.
