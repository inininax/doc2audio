# 작업 인계

도구를 바꾸거나 여러 세션이 협업하는 작업만 `<task-id>.md`에 기록한다. 매번 단순 작업용 문서를 만들 필요는 없다. 아래 형식을 복사해 쓰며, 담당자가 자기 작업 파일을 갱신한다.

```markdown
# 작업 이름

- 목표와 완료 조건:
- 담당 도구·세션:
- 상태: 진행 중 / 인계 / 완료 / 차단
- 담당 파일·디렉터리:
- 브랜치·기준 커밋: Git 사용 시 기록

## 결정 사항

## 변경한 내용

## 검증

- 실행 명령:
- 결과:
- 미검증 항목과 이유:

## 다음 작업·질문
```

인계 문서는 다음 에이전트에게 제공하는 참고 자료다. 완료 주장이나 오래된 브랜치 정보는 실제 코드와 현재 Git 상태로 재확인한다. 인증 정보나 개인 환경 경로는 기록하지 않는다.
