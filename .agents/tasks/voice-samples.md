# 목소리 샘플과 기존 Qwen3 사용 경로

- 목표와 완료 조건: 선택한 화자의 짧은 음성을 들을 수 있게 추가하고 기존 Qwen3 사용 경로를 UI와 실제 로컬 서버에서 확인한다.
- 담당 도구·세션: root 통합·서버·ego QA·문서, audit_engine 실제 샘플/생성 스크립트, ui_shell 플레이어·활성 상태 연결, design_references Qwen 안내·독립 UI 검토.
- 상태: 완료
- 담당 파일·디렉터리: apps/web/src, apps/web/public/voice-samples, scripts/generate_voice_samples.py, docs와 이 기록.
- 브랜치·기준 커밋: main / 2311a7c. 시작 시 clean, origin/main 일치.

## 결정 사항

- 모델 다운로드 전에도 비교할 수 있도록 같은 짧은 한국어 문장을 실제 설치 모델로 미리 생성한다. Supertonic 10개, Qwen 1.7B/0.6B 각각 9개 목소리다.
- 정적 샘플은 제품용 합성 음성 자산이며 개인 문서·개인 음성을 사용하지 않는다. 경로는 voice-samples/<model-id>/<speaker>.mp3, 생성 옵션·revision·해시를 manifest에 기록한다.
- 미리 생성한 샘플은 현재 입력문·배속·말투 설정과 별개임을 화면에 표시한다. 선택·화면 변경 시 재생을 정지한다.
- 현재 브라우저 구현은 Supertonic 전용이다. 기존 Qwen MLX 모델은 Apple Silicon Mac의 선택적 로컬 서버에서 계속 사용한다. 웹 전체에서 Qwen을 실행할 수 없다고 단정하지 않는다.
- Qwen 진입은 사용자의 명시적 링크 클릭으로 한다. 공개 웹에서 로컬 서버 자동 탐색이나 문서 자동 전송을 추가하지 않는다.

## 변경한 내용

- 선택 화자의 샘플 듣기·정지·불러오기 취소, 실패 안내, 비동기 재생 경합 방지와 화면 비활성 정지를 추가했다.
- 실제 Supertonic 10개·Qwen 각 9개 MP3와 생성 스크립트·manifest·출처/설정 README를 추가했다. 합계 2,592,618바이트이며 두 Qwen 화자의 엔진 재시도와 한 파일의 끝 여백 정리를 메타데이터에 기록했다.
- 새 음성 만들기와 모델 보관함에 Qwen 로컬 서버 사용 안내와 명시적 새 탭 링크를 추가했다.
- 추가 질문에는 공식 자료로 확인한 한국어 지원 무료 TTS 목록(Qwen3, Supertonic3, MeloTTS, CosyVoice3, MMS-TTS)을 채팅으로 제공했다. 이를 새 지원 모델로 등록하지는 않았다.

## 검증

- 세 모델 모두 로컬 설치됨을 필수 파일 검사로 확인.
- 웹 Vitest 110개 + SW Node 6개, 타입·웹 포맷·프로덕션 빌드, 생성 스크립트 Ruff lint/format, AI 환경 연결·diff 검사 통과.
- 독립 자산 검토: 28개 전체 ffmpeg 디코딩·MP3/PCM 고유해시·화자/옵션/리비전/길이 일치. 4.18~7.18초, 앞/뒤 무음 최대 0.310/0.364초. UI·Qwen 안내도 작성자 외 독립 검토 통과.
- 실제 ego: 모델 미설치 상태 F1/M1 재생, 재생 시작 0.16초 이후 화자 변경 시 pause/src 해제, 메뉴 이동 정지, 390px 가로 넘침 없음. 최종 빌드에서도 네트워크 차단 전후 probe 실패 상태로 미설치 F1 샘플 재생 성공.
- 실제 Qwen1.7B/Sohee 샘플 재생과 새 51자 문서의 7초 MP3 생성·저장·전체 디코딩 성공. Qwen0.6B/Sohee 샘플과 모델 변경 정지도 확인했다.
- 임의 개발 검증 포트 5193의 API 등록은 허용 출처가 아니어서 거절됐다. 보안 허용 목록을 변경하지 않고 지원하는 8010 동일 출처에서 재검증했다.
- 모든 브라우저나 사람의 청취에 따른 자연스러움을 평가한 것은 아니다. 샘플 기술 검사와 실제 브라우저 재생을 구분했다.
