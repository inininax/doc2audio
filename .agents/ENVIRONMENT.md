# 공용 AI 개발 환경

`AGENTS.md`와 `.agents/`에서 공통 지침을 관리한다. `CLAUDE.md`는 `@AGENTS.md`를 가져오고,
`.claude/rules`와 `.claude/skills`는 각각 `.agents/rules`와 `.agents/skills`의 상대 링크다.
애플리케이션 코드나 실제 스킬은 초기 구성에 포함하지 않는다.

## 사용과 관리

1. `.agents/PROJECT.md`에 확정된 목적·스택·실행 명령을 기록한다. 미정인 항목은 그대로 둔다.
2. 공통 규칙은 `.agents/rules/`만 수정한다. 규칙을 추가하면 `AGENTS.md` 읽기 목록에도 링크를
   추가한다. Codex가 `.agents/rules`를 자동 로딩한다고 가정하지 않는다.
3. 공용 스킬은 `.agents/skills/<skill-name>/SKILL.md`에 만든다. 이름이 전역 스킬과 겹치지 않게
   한다. 작업 인계가 필요하면 `.agents/tasks/README.md` 형식을 사용한다.
4. 프로젝트 루트에서 환경을 점검한다. Python 3.9 이상이 필요하다.

```bash
python3 scripts/ai-env.py check
python3 scripts/ai-env.py setup
```

`check`는 파일과 연결을 읽기 전용으로 검사한다. `setup`은 누락된 상대 링크만 만들고,
기존 파일·디렉터리·잘못된 링크가 있으면 보존하고 실패한다. 기본 파일이 삭제되었다면 버전
관리나 사용 중인 환경 설정 스킬의 템플릿에서 필요한 파일만 복구한다.

프로젝트 루트에서 Codex 또는 Claude Code의 새 세션을 시작하고 공통 지침·규칙·프로젝트
정보를 읽어 현재 개발 준비 상태를 알려 달라고 요청한다. 프로젝트 스킬을 추가했다면 각 도구의
스킬 목록에서 확인한다. 정적 검사 통과는 실제 세션의 지침 준수·스킬 실행 증거가 아니다.

## 독립성과 설정 범위

생성에 사용한 템플릿 프로젝트나 스킬 설치본은 이후 실행에 필요하지 않다. 프로젝트를 옮길 때
숨김 파일과 상대 심볼릭 링크를 보존하고 옮긴 위치에서 다시 `check`를 실행한다.
Windows에서는 디렉터리 심볼릭 링크 생성 권한이 필요하다.

모델·권한·인증·MCP·플러그인·hooks는 기존 사용자 설정을 따른다. 필요해진 도구별 프로젝트
설정은 각 도구의 현재 공식 형식에 맞춰 별도로 구성한다. CLI 설치·로그인, 의존성 설치,
Git 초기화·원격 반영은 이 환경 구성에 포함되지 않는다.

공통 지침·규칙·스킬·상대 링크는 버전 관리하고 개인 설정·세션 기록·비밀값은 제외한다.
`.gitignore`는 접근 제어나 비밀정보 검출을 대신하지 않는다.
