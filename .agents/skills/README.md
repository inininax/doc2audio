# 공용 스킬 위치

스킬 원본은 이 디렉터리에만 둔다. `.claude/skills`는 이곳을 가리키는 상대 심볼릭 링크다. 파일을 수정하거나 스킬을 추가하면 두 도구가 같은 원본을 참조한다.

현재 템플릿에는 실제 스킬이 없다. 이후 작성하는 스킬은 `<skill-name>/SKILL.md` 구조로 넣는다. 기본 frontmatter에는 `name`과 사용 시점을 설명하는 `description`을 두고, 부속 문서는 해당 스킬 디렉터리 안의 상대 경로로 참조한다.

공용 본문에는 특정 도구의 내부 명령, 절대 경로, 개인 계정 정보를 넣지 않는다. Claude 전용 실행 옵션·동적 치환과 Codex 전용 메타데이터는 공통 기능으로 가정하지 않는다. 도구별 기능을 추가했다면 각 도구에서 따로 확인한다.

전역 스킬과 겹치지 않는 이름을 사용한다. 환경이나 버전에 따라 중복 이름의 처리 방식이 다르므로 프로젝트 스킬이 전역 스킬을 덮어쓴다고 가정하지 않는다. Claude 예약 이름인 `synced`도 사용하지 않는다.

연결을 만든 뒤 두 도구에서 새 세션을 시작한다. Codex는 스킬 선택기, Claude Code는 `/skills`에서 나중에 추가한 스킬이 보이는지 확인한다. `README.md` 자체는 스킬로 등록되지 않는다.
