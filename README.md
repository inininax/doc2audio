# DOC2AUDIO

PDF·Word·텍스트 문서를 내 컴퓨터에서 읽어 MP3로 만드는 프로그램입니다. 문서와 생성 음성을 외부 변환 서버로 보내지 않습니다.

| 사용 방법 | 준비 | 기본 모델 |
| --- | --- | --- |
| 웹사이트에서 사용 | 사이트에 접속하고 브라우저에 모델 다운로드 | Supertonic 3 |
| Mac에서 직접 실행 | Apple Silicon Mac에 프로그램 설치. 터미널 또는 로컬 웹 화면으로 사용 | Qwen3-TTS 1.7B · 한국어 Sohee |

## 설치와 사용

- **[설치 안내](docs/installation.md)**: 필요한 도구, 프로그램과 모델 설치, 로컬 웹 실행, 웹사이트 배포
- **[사용 안내](docs/usage.md)**: 문서 변환, 목소리와 속도 조절, 결과 저장, 이어하기, 오프라인 사용, 문제 해결

웹사이트 이용자는 개발 도구나 Python을 설치할 필요가 없습니다. 웹에서 **모델 보관함 → 모델 다운로드 → 새 음성 만들기** 순서로 시작하세요.

Mac 설치를 마쳤다면 프로젝트 폴더에서 다음 명령으로 변환합니다. 문서 이름은 실제 파일 경로로 바꾸세요.

```bash
uv run doc2audio "문서.pdf" -o "결과.mp3"
```

PDF·DOCX·DOC·UTF-8 TXT를 지원합니다. 웹과 Mac 프로그램은 모델·작업을 각각 보관하며 서로 자동으로 옮기지 않습니다.
